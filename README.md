# Hackathon Atlas · 全球黑客松获奖作品库

**Build. Win. Inspire.**

在线浏览：https://hackathon-winners-atlas.vercel.app/

收录国内外黑客松获奖作品，按月份、地区和软件/硬件分类，支持搜索、深浅主题与离线浏览。

当前线上版本：v1.5.1（2026-11-24），82 条获奖记录、22 场赛事、19 项硬件分类。收录并非全球完整名单；媒体和奖项以原始资料为准。

## 维护约定

后续每次更新 UI、作品数据或功能，应先将源码及变更记录提交到本仓库，再发布正式站点，核对版本与访问结果。第三方图片须保留原作者及适用许可，不使用 AI 生成图片冒充真实作品。
